# ALRAEBI AUTO CARS — FINAL MASTER

هذه النسخة هي نقطة العمل النهائية المقترحة للمشروع، وليست مجرد ترقيم جديد.

## المكتمل
- واجهة RTL فاخرة ومتجاوبة.
- 8 صفحات سيارات وصور المشروع.
- بحث، فلاتر، مفضلة، مقارنة، تمويل، واتساب.
- Cloud-first inventory مع fallback محلي للواجهة.
- حسابات العملاء السحابية وطلباتي والإشعارات.
- طلبات شراء واستفسارات وتجارب قيادة.
- لوحة إدارة سحابية: سيارات، صور، طلبات، حجوزات، استفسارات، عملاء.
- عروض وكوبونات.
- إعدادات المعرض وسجل العمليات.
- تصدير نسخة احتياطية JSON.
- PWA / manifest / service worker.
- Docker وNode 20+.
- Helmet + rate limit + JWT + bcrypt.

## تشغيل السيرفر
1. ثبّت Node.js 20 أو أحدث.
2. افتح مجلد `server`.
3. `npm install`
4. انسخ `.env.example` إلى `.env` واضبط `JWT_SECRET` و`ADMIN_PASSWORD` بقيم قوية.
5. `npm start`
6. افتح الموقع عبر `http://SERVER:3000`.

## مهم للإنتاج
SQLite مناسب كبداية لسيرفر واحد. عند التوسع يمكن نقل قاعدة البيانات إلى PostgreSQL. صور الرفع موجودة في `server/uploads` وتحتاج volume دائم عند استخدام Docker.

## Acode
يمكنك تعديل الواجهة من الهاتف، لكن تشغيل الـ Backend السحابي يحتاج Node.js/VPS أو استضافة تدعم Node. فتح HTML مباشرة من Acode يعمل للواجهة المحلية، أما Cloud API فيحتاج السيرفر.
