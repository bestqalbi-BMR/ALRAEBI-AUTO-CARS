# ALRAEBI AUTO CARS V19 — FINAL CLOUD PRO

نسخة نهائية محسّنة لمعرض الراعبي أوتو كارز.

## التشغيل
- Node.js 20+
- داخل server: `npm install` ثم ضبط `JWT_SECRET` و`ADMIN_PASSWORD` ثم `npm start`
- افتح الخادم على المنفذ 3000 افتراضياً.

## المزايا
- API-first inventory CRUD
- رفع صور متعددة
- سيارات مميزة
- العملاء وتسجيل الدخول
- الطلبات + حالات الطلب
- الاستفسارات والحجوزات
- إعدادات المعرض
- سجل العمليات
- PWA
- Docker
- SQLite WAL + حماية Helmet + Rate Limit
- واجهة تعمل محلياً عند عدم توفر السحابة

## مهم للإنتاج
استخدم أسراراً قوية عبر متغيرات البيئة، وHTTPS، ونسخاً احتياطية دورية.
